Esta página é estática. Para hospedar arquivos de verdade, conecte seu próprio projeto Supabase com um bucket público chamado videos e uma política de upload anônimo limitada. O site não contém chaves secretas.

Qualquer pessoa com acesso à política de upload pode enviar conteúdo. Configure limites, moderação e regras no provedor. Não coloque uma chave service_role neste site.
